# 班级之星

手机和电脑均可使用的每周班级积分工具。

## 上传部署
您的仓库已启用 GitHub Pages。解压后，将 index.html、style.css、app.js、core.js、xlsx.full.min.js 和 .nojekyll 上传到 schoolproj_b 仓库根目录，替换现有 index.html。GitHub 将自动重新发布。

## 功能
导入 Excel (.xlsx)、CSV 或粘贴名单；按学生、日期、分类记加减分；按周汇总和同分并列排名；导出明细表及荣誉榜 PNG，长名单分页；JSON 备份及恢复。

## 使用
导入学生名单 → 在评分分类中设置班规 → 点击学生姓名记分 → 选择图片类型 → 导出图片。

每周初始分为 0。分类为可编辑的建议值，未从参考图中猜测不明确的规则。

记录仅存在当前浏览器，不上传服务器，也不会自动跨设备同步。换设备、换域名或清理浏览器前，请导出备份，到新设备或正式网址恢复。建议每周备份。

Excel 组件为 SheetJS CE 0.20.3 (Apache-2.0)，包含在部署包中。

## 本次更新
底部固定五栏：首页、积分总览、荣誉榜单、记录明细、评分分类。首页实时展示所选周前十名次（含并列）与负分学生名单，并分别导出 PNG。积分总览中点击姓名旁的改名可修改学生姓名，学号及历史积分不变。

## 手机桌面与简洁表格
首页点击「添加到手机桌面」。安卓 Chrome/Edge 支持时显示原生安装按钮；iPhone Safari 通过分享菜单添加到主屏幕。首次联网加载后可离线使用。不同浏览器或独立应用可能具有不同存储空间，如记录为空请恢复备份。

导出每周积分表为白底黑线，总分列浅蓝底红字。班级设置可填写导出表格标题，如「班级之星评比（第7周）」。周末有扣分时自动显示周末列，避免遗漏。

统计卡片仅显示在首页，其他栏目保留精简的「班级积分」标题。
