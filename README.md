# 班级之星

适合手机与电脑的班级每周积分工具。无构建步骤，无服务器数据库。

- Excel (.xlsx)、CSV、文本和粘贴名单导入，按学号检查冲突。
- 自定义评分分类、默认分数和简称，记录日期与备注。
- 按周计算积分、保留历史、同分并列评选班级之星。
- 导出每周明细 PNG、荣誉榜 PNG，长名单自动分页。
- 浏览器本地存储，完整 JSON 备份与恢复。

## 使用

导入名单 → 点击学生姓名或「记一笔」 → 选择日期、分类、分数 → 导出图片。

分类是可编辑的建议值；请按班级实际规则设置。每周初始分为 0。

学生与记录仅保存在当前浏览器中，不上传至 GitHub 或服务器。电脑和手机不会自动同步；换设备前请导出备份，再在新设备恢复。浏览器清理会删除本地数据，建议每周备份。

## 部署

GitHub 仓库 Settings → Pages → Source 选择 GitHub Actions。本仓库工作流会在 main 更新时自动部署。

发布地址以 GitHub Pages 工作流返回的地址为准。

Excel 读取使用 SheetJS CE 0.20.3（Apache-2.0），组件随站点提供。原仓库中未配套程序的首页保留于 legacy/index.html，亦可从 Git 历史找回。
